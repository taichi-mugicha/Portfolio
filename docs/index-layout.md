# indexページ レイアウト仕様

ポートフォリオのトップ（作品一覧）ページのレイアウト仕様と要望をまとめる。
実装は [index.html](../index.html) 内の `.top` セクション。作品カードをタップすると[作品ページ](work-detail-layout.md)（ボトムシート）が開く。

---

## 全体方針

- モバイルファースト（コンテンツ幅 `max-width: 430px` の1カラム、中央寄せ）。
- ページ背景は `#dcdcdc`、コンテンツ面は白 `--bg: #ffffff`。スマホ実機に載せたような見え方。
- 初回ロード時に挨拶スプラッシュ（「こんにちは 👋」）を表示。

## フォント

和文は **Noto Sans JP**（Google Fonts / `<head>` で読み込み）。ウェイトは 400・500・600・700 を読み込む。
欧文はこれまでどおり端末のシステムフォント（`-apple-system` ほか）。読み込めない環境では端末のゴシックにフォールバックする。

### タイプスケール（index・作品詳細 共通）

| 役割 | サイズ | 字間 | 行間 | 太さ |
|---|---|---|---|---|
| カルーセルのキャプション（タイトル） | 14px | +0.05em | 1.5 | 600 |
| 作品タイトル・結果の数値 | 32px | -0.02em | 1.1 | 700 |
| セクション見出し | 22 / 20px | -0.02em | 1.3 | 600 |
| カードタイトル・ロゴ | 16px | +0.05em | 1.5 | 600（ロゴ700） |
| 本文・概要・関連作品名 | 14px | +0.05em | 1.65 | 400 |
| タグ・補助テキスト | 12px | 0 | 1.5 | 400 |
| ラベル・キャプション・番号 | 11px | 0 | 1.5 | 400（ラベル600） |

- 字間は**20px以上の見出しが -0.02em**、**16px・14px が +0.05em**（和文を少し開けて読みやすく）、12px以下は 0。
- 行間は**見出し 1.1〜1.3 / 本文 1.65 / 補助 1.5** の3系統。
- 太さは **400 / 600 / 700** の3段のみ。

## カラートークン

| 変数 | 値 | 用途 |
|---|---|---|
| `--ink` | `#0a0a0a` | 装飾の塗り専用（ドット・タブ下線バーなど）。テキストには使わない |
| `--text-main` | `rgba(0,0,0,.96)` | メインテキスト（作品タイトル・選択中の年タブ・キャプションのタイトル行・フッターのロゴ名 など）。index・[作品詳細](work-detail-layout.md)で共通 |
| `--text-sub` | `rgba(0,0,0,.54)` | サブテキスト（カードのタグ・番号・年タブ非選択・年の一言紹介・キャプションのコンセプト行・フッターの年号 など）。index・[作品詳細](work-detail-layout.md)で共通 |
| `--bg` | `#ffffff` | コンテンツ面の背景 |
| `--ph` | `#ececec` | 画像プレースホルダー |
| ページ地色 | `#dcdcdc` | body 背景 |

## 構成（上から順に）

Figma「Claude-Labo」node 553:186（パターンA）に合わせて2026.09に全面刷新。ロゴとヒーロー見出しのテキストは廃止し、
画像カルーセル中心の構成にした。

1. **ナビバー** — 高さ52px。左右に要素を1つずつ配置。左はロゴが入る想定のプレースホルダーテキスト`Ta`
   （20px / 600 / -0.02em、Figma node 601:508を参考。正式なロゴが決まるまでの仮表記）、右にハンバーガーメニュー
   （現状は見た目のみ）。
2. **ヒーローカルーセル** — `WORKS` に `pickup:true` を付けた作品（現在5件）だけを自動でめぐる1枚カルーセル
   （全作品ではない）。カード比率はモバイル（〜639px）が
   縦長の**縦:横=3:2**（`aspect-ratio:2/3`）、640px〜のタブレット・PCでは横長の**横:縦=3:2**（`aspect-ratio:3/2`）に
   切り替わる（横に広い画面で縦長カードのままだと間延びするため）。
   `.top__inner` の左右パディング（`--content-pad`）を負のマージンで打ち消して**画面幅いっぱい**（角丸なし）に広げる。
   画像は `object-fit: contain` で切り抜かずに全体を表示し、余った上下（または左右）は背景色 `#f5f5f5` の単色塗りのまま
   見せる（`object-fit: cover` によるトリミングはしない）。画像下には白いグラデーション「座布団」
   （`linear-gradient(to right, rgba(255,255,255,.94)→0)`、画面左が不透明・右に抜ける）を敷き、その上に
   キャプション（1行目＝**作品名**14px `--text-main`、2行目＝**コンセプト**10px `--text-sub`。コンセプトは
   POINT OF VIEW＝コンセプト節の見出しをそのまま流用し、pov未設定の作品はカテゴリタグで代用）を重ねる。
   スライドが表示されるたび（自動送り・ドット・スワイプ問わず）、座布団とキャプションを
   `transform:scaleX(0)→(1)`（`transform-origin:left`）と `opacity:0→1` でリセットし、**画面左から伸びてくる**
   アニメーションを毎回掛け直す。4.5秒ごとに自動送り、下のドット（左寄せ、Figma通り）をタップすると
   手動でジャンプ（タイマーは再スタート）。カルーセル自体をタップすると該当作品のシートを開く。
   左右スワイプ／マウスドラッグでも送れる（挙動は[作品詳細のページャー](work-detail-layout.md)と同じ考え方：
   動き始めの6pxで横方向のドラッグだけ確定し、縦スクロールとは衝突しない。ドラッグ後のクリックは1回だけ抑制し、
   スワイプの指離しでシートが開いてしまわないようにする）。カルーセルと下のドットのあいだは16px、
   ドットから年タブまでは40px（詳細は下の「レスポンシブ」参照）。
3. **年タブ** — 作品データの `period` から開始年を抽出して重複なく降順に並べる（固定リストではない）。
   選択中の年は太字＋`--text-main`＋黒下線、それ以外は `--text-sub` 色で下線なし。横スクロール可（隠しスクロールバー）。
   各タブは `padding:8px` を持つが、そのぶん最初のタブの文字がコンテンツ幅より右に寄るため、
   行全体に `margin-left:calc(16px - var(--content-pad) - 8px)` をかけて先頭タブの文字を
   カルーセルと同じ**16px**の位置で揃えている（詳細は下の「レスポンシブ」参照）。
4. **年の一言紹介** — 年タブの下に、その年の作品を一言で紹介するテキストを1行表示。マージンは上0・下16px
   （タブ直下にぴったり収まり、グリッドとは16px空ける）。タブ切り替えごとにフェードアウト→テキスト差し替え→
   ふわっと浮かび上がる（opacity + `translateY(6px)→0`）ディゾルブで表示を切り替える
   （`prefers-reduced-motion` では即時表示）。テキストは作品データから自動生成できる性質のものではないため、
   `YEAR_NOTES`（年をキーにしたJSオブジェクト、index.html内）に手書きで用意している。
   作品を増減・入れ替えたら内容が合っているか見直すこと。
5. **作品グリッド** — 選択中の年に該当する作品だけを表示。1カラム / gap 28px。左右余白は**8px**
   （カルーセル・年タブ・フッターの16pxより狭い。`.grid` に `margin:0 -8px` をかけて `--content-pad` との
   差分を打ち消している）。通し番号 `0X` は表示中の並びに対して振り直す（年をまたいだ通番ではない）。
6. **フッター** — `■ TAICHI ITO` と `© {今年}`（JSで動的に算出）。連絡先メールは載せない。

eyebrow（`UI / UX デザイナー — IoT・アプリ`）とSelected行（`Selected Work — 2020 / 2023` ＋ 総件数）は
2026.09の前段の整理で先に削除済み。

## レスポンシブ

モバイル（〜639px）が正で、それ以外は上書きのみ。ブレークポイントは2つ。

| 幅 | コンテンツ幅 | グリッド | カルーセル比率 |
|---|---|---|---|
| 〜639px | 430px | 1カラム / gap 28px | 縦長 2:3 |
| 640px〜 | 760px | 2カラム / gap 36px・24px | 横長 3:2 |
| 1024px〜 | 1100px | 3カラム / gap 44px・28px | 横長 3:2（640px〜と同じ） |

年タブ・フッターは全ブレークポイント共通（モバイル値のまま）。カルーセル比率のみ上表の通り640px〜で切り替わる。

- 左右の余白（`--content-pad`）は**全ブレークポイント共通で16px固定**。カルーセル・年タブ・フッターが
  同じ16pxの左右余白で揃う（safe-area-inset は別途加算）。上下のパディングはブレークポイントごとに広げる
  （14/20/24px・80/96/120px）。
- 年タブの各ボタンは可読性のため独自に `padding:8px` を持つため、タブ行に
  `margin-left:calc(16px - var(--content-pad) - 8px)` をかけて、先頭タブの文字がカルーセルと
  同じ16pxの位置で揃うように補正している。
- 作品グリッドだけは左右余白**8px**（`.grid{margin:0 -8px}`）と、他より狭い。サムネイルを画面幅に対して
  より大きく見せたい意図。
- `@media (hover:hover) and (pointer:fine)` の環境だけ、カードのホバーで
  サムネを `opacity:.86` に落とす。タップ時の `scale(.985)` はそのまま。
- 拡大縮小は禁止しない（viewport meta から `maximum-scale` / `user-scalable=no` を外した）。

## 作品カード

- サムネイル：アスペクト比 **4:3** / 角丸**4px** / `works/images/{slug}/01.png` を `object-fit: cover`。
- タップ時に `scale(.985)` で軽く沈む。
- メタ：サムネイル下 `margin-top:4px`。タイトル（16px / 600）＋ カテゴリタグ1つ（muted）を左、通し番号 `0X` を右（総件数は併記しない）。
- タップで該当作品のボトムシートを開く。

## スプラッシュ（挨拶）

- 「こんにちは 👋」を中央に表示。手を振るアニメーション付き。
- 初回訪問のみ最低 **1.2秒** 表示（一瞬すぎて見えない問題への対応）。再訪時は `sessionStorage` を見て即座に消す。
- `prefers-reduced-motion` でアニメーション停止。
- 調整値は `:root` 変数に集約（`--wave-duration` など）。
