# indexページ レイアウト仕様

ポートフォリオのトップ（作品一覧）ページのレイアウト仕様と要望をまとめる。
実装は [index.html](../index.html) 内の `.top` セクション。作品カードをタップすると[作品ページ](work-detail-layout.md)（ボトムシート）が開く。

---

## 全体方針

- モバイルファースト（コンテンツ幅 `max-width: 430px` の1カラム、中央寄せ）。
- ページ背景は `#dcdcdc`、コンテンツ面は白 `--bg: #ffffff`。スマホ実機に載せたような見え方。
- 初回ロード時に挨拶スプラッシュ（「こんにちは 👋」）を表示。

## カラートークン

| 変数 | 値 | 用途 |
|---|---|---|
| `--ink` | `#0a0a0a` | 基本の文字色 |
| `--muted` | `#737373` | 補助テキスト（タグ・番号・eyebrow） |
| `--bg` | `#ffffff` | コンテンツ面の背景 |
| `--ph` | `#ececec` | 画像プレースホルダー |
| ページ地色 | `#dcdcdc` | body 背景 |

## 構成（上から順に）

1. **ナビバー** — 高さ52px。左にロゴ `TAICHI ITO`（`■` プレフィックス）、右にハンバーガーメニュー（現状は見た目のみ）。
2. **ヒーロー見出し** — 36px / bold / line-height 1.02。例：「暮らしに寄り添う、IoT家電のUIを。」
3. **作品グリッド** — 1カラム / gap 28px。

eyebrow（`UI / UX デザイナー — IoT・アプリ`）とSelected行（`Selected Work — 2020 / 2023` ＋ 総件数）は2026.09に削除した。

## レスポンシブ

モバイル（〜639px）が正で、それ以外は上書きのみ。ブレークポイントは2つ。

| 幅 | コンテンツ幅 | グリッド | ヒーロー見出し |
|---|---|---|---|
| 〜639px | 430px | 1カラム / gap 28px | 36px |
| 640px〜 | 760px | 2カラム / gap 36px・24px | 46px |
| 1024px〜 | 1100px | 3カラム / gap 44px・28px | 60px |

- 左右パディングも 20px → 32px → 48px と広げる（safe-area-inset 込み）。
- `@media (hover:hover) and (pointer:fine)` の環境だけ、カードのホバーで
  サムネを `opacity:.86` に落とす。タップ時の `scale(.985)` はそのまま。
- 拡大縮小は禁止しない（viewport meta から `maximum-scale` / `user-scalable=no` を外した）。

## 作品カード

- サムネイル：アスペクト比 **4:3** / 角丸6px / `works/images/{slug}/01.png` を `object-fit: cover`。
- タップ時に `scale(.985)` で軽く沈む。
- メタ：タイトル（16px / 600）＋ タグ（`・` 区切り / muted）を左、通し番号 `0X` を右（総件数は併記しない）。
- タップで該当作品のボトムシートを開く。

## スプラッシュ（挨拶）

- 「こんにちは 👋」を中央に表示。手を振るアニメーション付き。
- 初回訪問のみ最低 **1.2秒** 表示（一瞬すぎて見えない問題への対応）。再訪時は `sessionStorage` を見て即座に消す。
- `prefers-reduced-motion` でアニメーション停止。
- 調整値は `:root` 変数に集約（`--wave-duration` など）。
