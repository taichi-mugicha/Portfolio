# 作品ページ レイアウト仕様

作品詳細をボトムシートで見せるページの仕様と要望をまとめる。
実装は [index.html](../index.html) 内の `.sheet` 一式。[indexページ](index-layout.md)の作品カードから開く。
流し込むテキストは [work-detail-text-format.md](work-detail-text-format.md)（項目と分量）と
[writing-style.md](writing-style.md)（文体）に準拠。

---

## 全体方針

- 一覧の上にせり上がる**ボトムシート**として詳細を表示（ページ遷移しない）。
- シート内は左右スワイプで作品間を移動できる**ページャー**。
  回遊できる範囲は入口で決まる：**カルーセルから開いたらピックアップ5作品**、**一覧から開いたら年をまたいで全作品**（新しい年→古い年の順）。
  ヘッダーの番号はその範囲での番号・件数で、見出しも入口で変わる：カルーセルから→`PICK UP ｜ 0N / 0M`、一覧から→`2025 ｜ 0N / 0M`（今いる作品の年と、その年の中での番号・件数。年をまたぐと切り替わる）。範囲が1作品なら `‹ ›` は出さない。
- ヘッダー（ハンドル部）を下方向にドラッグすると閉じる。
- `max-width: 560px` 中央寄せ。角丸は上端のみ24px。

## 開閉・背景

- **バックドロップ**：`rgba(0,0,0,.36)` ＋ blur 2px。タップで閉じる。
- シートは下から `translateY(100%) → 0` でスライドイン（`.42s` / ease `cubic-bezier(.22,1,.36,1)`）。
- 高さ `96vh`。

## レスポンシブ

| 幅 | シート | 本文パディング | ヒーロー比率 |
|---|---|---|---|
| 〜767px | 下端に貼り付く。max-width 560px / 高さ 96dvh / 角丸は上端のみ | 24px / 20px / 60px | 335:384 |
| 768px〜 | 同上。max-width 720px | 32px / 48px / 72px | 16:10 |
| 1024px〜 | **中央に浮かぶダイアログ**。max-width 960px / 高さ `min(88dvh,900px)` / 下 32px / 角丸 20px 全周 | 同上 | 16:10 |

- 1024px〜では、1ブロックに画像が複数ある場合（OVERVIEW・デザイン）、**画像だけを2列のグリッド**（`.img-grid`、画像間16px）で並べる。
  見出し・本文は全幅のまま。画像1枚のブロックは全幅。〜1023pxは従来どおり1列。
- 浮かせた分、閉じているときの `transform` は `translateY(calc(100% + 32px))`（下端に帯が覗くのを防ぐ）。
  開いたときの `translateY(0)` はブレークポイント共通。
- ページャーの位置は `%`（`translate3d(calc(-N*100% + ドラッグ量px),0,0)`）で指定する。px換算（整数に丸まる `clientWidth`）だと
  Pixel 7a（約411.4px幅）のような端数のある幅で後ろの作品ほどずれ、ヒーロー左に隙間が出るため。
  `resize` ではスワイプのしきい値用の幅だけ測り直す（120msデバウンス）。
- スワイプヒントの文言はポインタ環境では `← ドラッグ / ← → キー →` に差し替える。
- ホバー可能な環境のみ、`‹ ›` ボタンと関連作品にホバー状態を出す。ページャーは `cursor:grab`。

## ヘッダー

- 上端に**ドラッグハンドル**（38×4 / 角丸）。
- ナビ行：`32px / 1fr / 32px` グリッド。左に前へ `‹`、中央にタイトル、右に次へ `›`。
- タイトル：上段に `PICK UP ｜ 0X / 0N` または `2025 ｜ 0X / 0N`（10px / muted）、下段に作品名（13px / 600）。
- `PICK UP` / 年の行の上に **8px** の余白。
- ナビ行の下の余白（作品名の下〜本文の境目）は **8px**。

## スライド本文（上から順に）

1. **ヘッダーグループ**
   - ヒーロー画像：アスペクト比 **335:384** / 角丸なし。`.slide` の上・左右パディングを負のマージンで打ち消し、**画面幅いっぱい**（ヘッダー直下から）に敷く。
   - タイトル：**24px** / 700 / line-height 1.1 / `--text-main`。
   - メタ：期間（`YYYY.MM - MM`）のみ / `--text-sub`。タグは表示しない（一覧カードでのみ表示）。
   - OVERVIEW本文（14px / `--text-main`）：期間の下に20px空けて続ける。`OVERVIEW` の見出しラベルは出さない。直後に全体像の画像＋キャプション。
2. **コンセプト**（POINT OF VIEW）— グレーの箱（`#f3f3f3`）の中に「ラベル `コンセプト` → 見出し → 画像 → 本文」1件。
3. **デザイン**（DESIGN）— 「ラベル `デザイン 0N` → 見出し(22px) → 画像 → 本文」のブロックを必要数繰り返す。セクション全体のラベルは置かず、節ごとに連番ラベルを付ける。
4. **プロセス**（PROCESS）— 「見出し(20px) → 画像 → 本文」のブロックを繰り返す。
5. **結果**（OUTCOME）— 「数値(32px) ＋ 説明文」の行。背景 `#fafafa` / 角丸。データが無ければセクションごと非表示。
6. **ディバイダー**（1px）
7. **関連作品** — 次の2作品を自動表示（サムネ96px ＋ タイトル20px）。タップでその作品へジャンプ。

コンセプト以降の各セクションは、対応データが空なら丸ごと省略される。

## インタラクション

| 操作 | 挙動 |
|---|---|
| 左右スワイプ / マウスドラッグ | 前後の作品へ。**ループする**（最後→最初、最初→最後）。1作品のみのときは抵抗（0.35倍）。距離18% or 速度で確定。 |
| `←` `→` キー / `‹ ›` | 前後の作品へ（ループ）。 |
| ヘッダーを下ドラッグ | 140px超 or 速度でシートを閉じる。 |
| `Esc` / バックドロップタップ | 閉じる。 |
| 関連作品タップ | その作品スライドへ移動。 |
| スワイプヒント `← swipe →` | 開いて2.6秒後にフェードアウト。 |

## カラートークン

indexと共通。テキストは `--text-main`（`rgba(0,0,0,.96)`：タイトル・見出し・本文・数値など）と
`--text-sub`（`rgba(0,0,0,.54)`：期間・キャプション・補助テキストなど）の2トークンに統一している
（2026.09、`--meta` は廃止）。`--ink` `--muted` はドット・タブ下線などの装飾塗り専用でテキストには使わない。

| 変数 | 値 | 用途 |
|---|---|---|
| `--line` | `#e5e5e5` | 区切り線 |
| `--sheet-radius` | `24px` | シート上端の角丸 |

本文中の画像（`.sec-img`）と関連作品サムネ（`.related-thumb`）の角丸は **2px**。
本文中の画像のアスペクト比は **772:720**（`object-fit:cover`）。ヒーローとは別の比率。

## 要望・意図（随時追記）

- ページ遷移させず、一覧の延長でサッと詳細を見て、また一覧に戻れる体験にしたい。
- 2026.09 レスポンシブ対応。PCでは画面下端に貼り付いた縦長のシートが「スマホの見た目のまま」に
  見えてしまうため、1024px以上では中央に浮くダイアログとして扱う。下からせり上がる動きと
  ヘッダーの下ドラッグで閉じる操作は変えない。本文の行長が伸びすぎないようシート幅は760pxで止める。
- 作品間はスワイプでどんどん見比べられるように。
- テキストは案件ごとに分量が違うので、セクション（PROCESS / OUTCOME 等）が無い作品は自動で詰めたい。
- ~~DESIGNは「主張→根拠→ビジュアル」、PROCESSは「経緯→ビジュアル→補足」の順にしたい意図で画像位置を変えている。~~ → 2026.09 廃止。
- OVERVIEWにはアプリ全体像がわかる画像、POINT OF VIEWにはユーザー/製品の課題がわかる画像を追加したい（[work-detail-text-format.md](work-detail-text-format.md)参照）。
- 本文中の全画像にキャプションを小さく添えたい。画像の下に控えめなテキストで1行表示するイメージ。
- 2026.09 作品詳細のタグ表示を削除。タグは一覧カードで見せれば足りるので、詳細は期間だけにして見出しまわりをすっきりさせる。
- 2026.09 ヘッダー下のプログレスドットを削除。現在地は `CASE 0X / 0N` の表示で足りるため。
- 2026.09 OVERVIEWを見出しなしで期間の下に置く。タイトル・期間・概要をひとかたまりで読ませ、冒頭のラベルを1つ減らす。
- 2026.09 Figma（Claude-Labo / node 571-206）を参考にレイアウト変更。ヒーローを画面幅いっぱいに、本文画像・関連作品サムネの角丸を2pxに。各セクションのラベルを日本語化（コンセプト / デザイン 0N / プロセス / 結果）。原稿（`works/*.md`）の `##` 見出しは英語のまま。
- 2026.09 セクションラベル（コンセプト / デザイン 0N / プロセス / 結果 / 関連作品）の太さと色を、直下の見出しと揃える。コンセプトは 700 / `#000`、それ以外は 600 / `--ink`。サイズ（10px）は据え置き。字間は英字大文字用の `1.5px` をやめて `0` に。
- 2026.09 コンセプト・デザイン・プロセスのブロック構成を「見出し → 画像 → 本文」に統一。画像の後の本文は12px空ける。
- 2026.09 indexページと文字色を統一。`--ink` `--muted` `--meta` `#000` などバラついていたテキスト色を
  `--text-main`（`rgba(0,0,0,.96)`）／`--text-sub`（`rgba(0,0,0,.54)`）の2トークンに集約し、`--meta`は廃止。
  あわせて作品タイトル（`.s-title`）を32pxから**24px**に縮小。

- 2026.09 本文中の画像（コンセプト/デザイン/プロセス）をより縦長に。高さを1.5倍にし、比率を772:480→772:720に変更（実画像もobject-fit:coverで揃える）。ヒーロー画像は対象外（変更なし）。
- 2026.10 シートの回遊範囲を入口ごとに限定。カルーセルから→ピックアップ5作品、一覧から→その年の作品。
- 2026.10 Pixel 7a（411dp）で空気清浄機・省エネレポートのヒーロー左に隙間が出る不具合を修正（ページャー位置をpx→%指定に）。
- 2026.10 PC（1024px〜）のダイアログ幅を広げる。max-width 760px→960px。
- 2026.10 PCサイズ（1024px〜）で作品詳細の画像のみ2列に（画像間16px）。ブロックごと2列にする案は撤回。
- 2026.10 シートのヘッダー表記を `CASE` から入口別に。カルーセル→`PICK UP 01 / 05`、一覧→`2025 01 / 03`。
- 2026.10 ヘッダーの作品名の下の余白を16px→8pxに。
- 2026.10 シートの回遊をループに（PICK UP・年ごとのどちらも）。両端に複製スライドを置き、複製へ流れたらアニメーション後に本物へ瞬時に戻す方式。
- 2026.10 一覧から開いたときの回遊を年ごと→年をまたいで全作品に。ヘッダーの年・番号は今いる作品の年で切り替わる。`PICK UP`/年の行の上に8pxの余白。
- 2026.10 ヘッダーの作品名が英字のみ／日本語入りで高さが変わりガタつくのを修正。行の高さを固定（ラベル16px・作品名20px）、長い作品名は1行で省略。
- 2026.10 期間の区切りを「~」→「-」に（例 `2022.10 - 2023.03`）。原稿・`WORKS`・フォーマット定義すべて。
- 2026.10 カルーセルから開いたときのヘッダー表記を `PICK UP｜01 / 05` に（全角縦線の前後は詰め、スラッシュの前後は空白あり）。
- 2026.10 一覧から開いたときのヘッダー表記も `2025｜01 / 03` にそろえる。
- 2026.10 ヘッダー表記の全角縦線の前後に空白を入れる（`PICK UP ｜ 01 / 05`、`2025 ｜ 01 / 03`）。
